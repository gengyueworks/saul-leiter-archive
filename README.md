## 核心特性 / Features

- **100% 官方基金会真迹 / 100% Saul Leiter Foundation Source**: 直连官方基金会四大馆藏专栏，精选收录 115 幅高画质原作，彻底清空旧版网络杂质与低清二手散图。
- **经典四大体系全覆盖 / Iconic Series**:
  1. **纽约彩色经典 (Color Photographs)**：26 幅传世彩色街头（红色雨伞、车窗雨雾倒影、黄色出租车、过客）；
  2. **早期黑白光影 (Black & White)**：34 幅充满绘画光影张力与构图深度的黑白纽约切片；
  3. **彩绘摄影 (Painted Photos)**：25 幅摄影冲印与水彩/丙烯颜料结合的跨界艺术实验；
  4. **抽象绘画手记 (Paintings)**：30 幅画家雷特的私密画室心象。
- **双视图体验 / Dual View Modes**:
  - 📱 **灵感流 (Feed)**：沉浸单列画卷，向上轻划连续品读色彩的呼吸与停顿；
  - 🔲 **瀑布流 (Masonry)**：多列精细网格，全景纵览色块结构与视觉节奏。
- **双主题支持 / Paper & Dark Themes**: 默认温润银盐纸质底色（Paper），一键切换暗室沉浸黑（Dark）。
- **全功能手势灯箱 / Interactive Lightbox**: 手机端触摸滑屏翻页、桌面键盘方向键切换与 ESC 退出。
